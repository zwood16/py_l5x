# Py_l5x

A pythonic interface for reading, writing, and creating L5X files.

> [!IMPORTANT]
> **⚠️ Work in Progress**: This project is currently under active development. APIs are subject to change, and not all features may be fully implemented or tested.

`py_l5x` is a python package that provides a high-level, pythonic way to interact with Rockwell Automation L5X files, making it easier to programmatically analyze, modify, and generate PLC project exports.
